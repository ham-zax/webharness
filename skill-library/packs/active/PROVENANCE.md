# active collection provenance

Imported from the operator My Skills backup: the directly active Skillshare skills, including the bundled Aegis method pack. Copies are standalone; no source checkout is required at runtime. Source frontmatter is preserved.

Availability is not proof of host compatibility or license to redistribute. Review upstream rights for each copied skill before redistributing this pack.

## Packaging adaptations

Copied development tests and a stale open-websearch backup are omitted. Impeccable's
font index and every remaining runtime helper are bundled and policy-approved.
Claive and Khiip workstation paths use $HOME instead of a named user's home.
These path adaptations do not change their workflow or permission rules.
