# Provocation (Po)

Use this method when a rule, constraint, or convention feels like physics and needs to be deliberately broken.

## Workflow

1. Confirm the target and identify the convention or constraint that feels fixed.
2. List 4-6 operating rules as flat declarative statements. If fewer than four meaningful rules exist, the target is probably too vague.
3. Generate 4-6 one-line provocations prefixed with `Po:`. Cover at least three of these five operations:
   - Escape: remove a supposedly necessary component entirely.
   - Reversal: swap the direction of a relationship.
   - Exaggeration: push a quantity to zero or an impossible extreme.
   - Distortion: reorder steps or swap roles.
   - Wishful thinking: state an impossible desired outcome as already true.
4. Make each Po clearly unreasonable as a proposal. If it sounds defensible already, push it further.
5. For each Po, extract movement without judging the Po itself:
   - Principle: what general idea hides inside it?
   - Moment-to-moment: if literally true, what happens first, second, third?
   - Difference: what changes relative to today?
6. Shape only live movement into a concrete direction. If two honest attempts produce no movement, abandon the Po visibly.
7. Scan the batch for a meta-pattern across what moved and what did not.
8. Rank 2-4 sharpest directions, name weak ones, and offer next moves without forcing a decision.

## Templates

- Escape: `Po: [system] has no [assumed component].`
- Reversal: `Po: [normally passive party] acts on [normally active party].`
- Exaggeration: `Po: [quantity] is zero / instantaneous / one million.`
- Distortion: `Po: [later step] happens before [earlier step].`
- Wishful thinking: `Po: [impossible desired outcome] happens automatically.`

## Honesty mechanics

Expect about one in three provocations to fail. Show the failure rather than turning the Po into a safe suggestion.

If almost nothing moves:

- If the rules cannot be named, suggest Random Stimulus next.
- If every Po returns to the same idea, suggest Concept Fan next.

Do not run the suggested method in the same pass.

## Prohibitions

- Do not defend or attack a Po; it is a stepping stone, not a proposal.
- Do not jump directly from Po to polished idea without movement work.
- Do not run more than eight provocations in one batch.
