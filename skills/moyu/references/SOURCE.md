# Source and adaptation

This skill is adapted from the Moyu anti-over-engineering framework by Tayer Ruze (`uucz/moyu`).

Source: https://github.com/uucz/moyu
License: MIT

The adaptation keeps the simplicity and scope-control philosophy while composing with Causal Coding: testing is opt-in rather than an automatic correctness ritual, required transitive file changes are allowed, process overhead must justify itself, non-test evidence stays proportional to the affected contract, and the agent asks at architectural/ownership boundaries rather than requiring explicit permission for every file not named in the prompt.
