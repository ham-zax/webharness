# Performance and communication playbook

Load this playbook when the selected episode asks the learner to communicate in a real or required context: conversation, interview, professional, academic, persuasive, or another explicit register/modality target.

## Use a real artifact or scenario

Prefer practice around something the learner actually needs to say or do:

- interview answer;
- explanation;
- message or email;
- presentation segment;
- difficult conversation;
- spontaneous response;
- role-play matching the required context.

If no real artifact exists, create the smallest plausible scenario that exercises the frozen target.

## Learner first, model second

For production and repair:

1. collect the learner's wording before model wording is visible;
2. assess against the frozen criteria and active register;
3. identify the highest-value communication issue, not every possible edit;
4. explain why it matters;
5. only then offer a refined version when useful;
6. preserve the learner's voice unless correctness, clarity, function, or register requires a change.

Do not rewrite toward generic corporate polish.

## Fluency mode

When the learner has already demonstrated the underlying rule and the selected goal is contextual performance:

- let the interaction run long enough to require real retrieval and organization;
- prefer selective recasts or concise post-turn feedback over constant interruption;
- suspend "explain why" prompts unless the mechanism actually fails;
- treat structures such as PREP, What-So What-Now What, or Problem-Solution-Benefit as optional scaffolds, never mandatory scripts;
- use paraphrasing and clarification as valid conversational moves rather than signs of failure.

## Delivery and transcript limits

Coach only what the evidence source can support.

- Transcript text can support wording, structure, register, and retained filler patterns subject to the ASR gate.
- Missing filler tokens do not prove filler-free speech.
- Transcript alone cannot prove prosody, pronunciation, pause timing, pace, pitch, or vocal confidence.
- If delivery itself is the target, require a modality that can expose it rather than inventing a conclusion from text.
